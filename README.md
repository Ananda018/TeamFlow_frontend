# TeamFlow Frontend

This is a starter React + Vite project modeled after the structure and conventions from the source project.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`

## Structure

- `src/app` for Redux store setup
- `src/components` for reusable UI components
- `src/features` reserved for feature modules
- `src/routes` for route setup
- `src/services` for network and helper services
